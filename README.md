### What I learned


Through this project, I improved my understanding of:

- CSS Grid layouts using `grid-template-areas`
- Responsive web design
- Combining Flexbox and Grid together
- Image positioning and overflow handling
- Mobile responsive layouts using media queries

Example of the grid layout used:

css
.container{
    display:grid;
    grid-template-areas:
        "card7 card1 card1 card4"
        "card7 card1 card1 card4"
        "card7 card2 card3 card4"
        "card8 card2 card3 card4"
        "card8 card6 card5 card5";
}
